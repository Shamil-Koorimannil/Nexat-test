# NEXAT Construction - Projects Portfolio Database

This document serves as the master copy and content specification for the **Projects Section** of the NEXAT Construction website. It organizes project data from both the standard portfolio packages (`companyData.js`) and the specialized structural engagements (`ShopsGallery.jsx`), providing full English and Arabic copywriting, technical specifications, metadata, and rendering guidelines.

## 3. Implementation Recommendations for React/TypeScript
1. **Context Bindings:**
   Ensure your components hook into the `useLanguage` translation provider so that toggling the Arabic/English selector updates labels, categories, and technical descriptions seamlessly.
2. **Path Resolution:**
   Keep all background media files under the `/public/assets/` folder structure, matching filenames exactly (e.g. `project_tower.png`, `project_civic.png`, `six_flags_showcase.png`, `project_villa.png`, `headquarters.png`).
3. **CSS Class References:**
   * Grid alignment: `grid grid-cols-1 md:grid-cols-2 lg:grid-cols-3 gap-6`
   * Image zoom: Add `.hover-zoom-container` on card wrapper and `.hover-zoom-image` (configured with `transition-transform duration-700 hover:scale-105`) on images.
